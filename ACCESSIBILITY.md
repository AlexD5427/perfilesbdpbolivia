# Accessibility

The portal uses semantic headings, landmarks, skip navigation, visible controls, keyboard-friendly forms, color-independent tags, responsive layouts, reduced-motion CSS, theme controls and a large-text preference. Media must receive captions, transcripts and alt text when introduced.

Run axe-based automated checks and manual keyboard/screen-reader review before bank publication. The legal accommodation language and final WCAG 2.2 AA conformance statement require review.
